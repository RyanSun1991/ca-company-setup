# 11 · 簿记与证据:台账体系、凭证目录、公司抬头采购、订阅与 AI 工具税务标记、设备到货登记、给会计师的包

## 目标
每一笔钱、每一个账号、每一张票在发生当天就有一行记录和一个 PDF;季度 GST 申报 Claude 10 分钟算完;秋季会计师拿到的是一个目录而不是一堆问题。

## 前置条件
- 档案仓库与总控(14);RT 账户与生效日(04);公司账户(05);公司信用卡(有则更顺)。

### 2. 凭证目录规则
- 按季度建目录(与 GST 申报期一致);README 一句话列本期应有票据(如:NUANS ×2、虚拟地址 8 月/9 月、EOR 押金发票、EOR 首张工时发票、公司名义购买的设备/软件)。
- 每张 PDF 一份;文件名 `<供应商>-<单号>-<日期>-HST<金额>.pdf`。
- 同一张票若也属合同包(EOR 发票),两处各存一份。
- 保险、银行费、政府规费、美国 SaaS 不进凭证目录(无可抵 HST),但订单台账要记(T2 可扣)。
- 发票日期决定归属期(开票即"应付",未付款也可抵);漏抵 4 年内补。

### 3. 公司抬头采购(≥$500 的票必须收件方 = 公司)
- 用公司账户/公司卡付;**Apple 官网**:普通结账没有公司抬头字段 → 走 **apple.com/ca_smb_en/shop**(小企业商店,免注册 Continue as Guest),收货地址勾 **"This is a business address"** → 出现 **"Company Name (optional)"** 填公司名(姓名栏仍填收件人本人);Business Team 电话可谈企业价;**别用教育商店(UNiDAYS/ca-edu)买公司设备**(资格属个人,有被取消订单/补差风险,发票也可能是个人名);**Amazon Business 账户免费**出合规发票;Best Buy / Apple Canada / Amazon 自营收据印税号,第三方卖家看 "Sold by"。
- 公司卡未下来前个人卡付 + 月度报销单(ETA s.175),发票仍开公司名。
- 收货地址可填家庭地址,ITC 看收件方名称不看送货地。
- Apple 大件订单在**发货时**才开最终发票 → 税落发货月所在季度;订单确认邮件先归档,最终发票 PDF 到手存对应季度。

### 4. 订阅与 AI 工具的税务标记(四步,"抬头/税号/付款/用途四一致")
1. **判定用途**:只列用于公司业务的订阅;与另一份全职工作/个人混用按合理比例(如 80%)并写理由。
2. **改抬头 + 填税号**:供应商 Billing 里账单名称改公司法定名、地址改注册地址、**Tax ID 填 CA GST/HST `<BN>RT0001`**、账单邮箱改 `billing@`。Claude(claude.ai)入口:Settings → Billing → 付款方式旁 Update → Tax/VAT ID 字段(support.claude.com 有帮助文章)。
3. **改付款方**:公司卡批下后换;之前个人卡付的每月一张报销单(日期/供应商/CAD 实付/业务比例/收据),公司 e-Transfer 给个人,备注 "Expense reimbursement <月>"。
4. **留票**:每月 PDF 存凭证目录;科目 GIFI 9150 Computer-related expenses。
**三类 GST 情形**(看发票税行):A 海外供应商简化登记制(多数 AI 公司对个人用户)— 列了 GST/HST 也**不可抵**,填公司税号后不得再收,已收的申请退还(CRA Notice 322;核对 "Confirming a simplified GST/HST account number");B 海外供应商未收税(USD 计费常见)— 无 ITC,进口服务 ≥90% 商用**不需自评**(ETA s.218),所得税侧按 CAD 实付全额扣,外币手续费也可扣;C 正常登记供应商(Apple Canada、Google、Microsoft、AWS Canada、Adobe、Shopify、本地 SaaS)— 按三档凭证抵。
**SR&ED 口径**:代理法下软件订阅属间接费用已由 55% 代理额覆盖,不单列;研发日志注明用到的 AI 工具即可。
**Apple/Google 开发者年费**:挂个人账户时不是公司支出;迁移到组织账户后由 Apple Canada 开票才可抵。

### 5. 设备到货登记(资产台账 + 凭证 + 保险清单三合一)
到货当天:型号 / 序列号 / 购买日 / 含税金额 / HST / 用途(开发主机、测试设备…)/ 使用人 / 商用比例(>50% → HST 抵 100%)/ CCA 类别(电脑 Class 50、手机与家具 Class 8;Watch 类测试设备按会计师意见)/ 凭证路径。以旧换新退款:旧设备是个人资产,退款打到公司卡/账户 → 记股东借款;打到个人卡 → 与公司无关。个人旧设备转公司:FMV Bill of Sale + 董事决议(04 §8)。

### 6. 给会计师的包(首个财年秋季)
- 目录索引:注册文件、Minute Book(含 IP 转让协议与 s.85 决定项)、股东借款台账、银行流水、凭证目录全部季度、ITC 清单、订阅台账、资产台账、EOR 合同与全部发票、保险保单、收款平台月结单与首笔打款记账口径、Apple 迁移完成日与个人期报告、SR&ED 记录表 + git 提交导出 + 员工日志按类别汇总。
- **问题清单**(真实项目):① 税务居民 / CCPC 书面确认;② IP 转让是否做 s.85 选举、T2057、elected amount(转让年度最早申报截止前);③ Apple 平台收入在公司 GST 申报中的呈报口径(GST/506 代理人模式);④ SR&ED 资格(EOR 合同款 80%)与 OIDMTC(安省互动数字媒体抵免 35–40%,需 Ontario Creates 认证)评估;⑤ 创始人薪酬时点、配偶雇佣、PHSP;⑥ CCA 首年规则(生产力超级扣除);⑦ 个体户历史 GST 账户处置;⑧ 海外子公司 T1134/T106 申报评估;⑨ T2 财年后 6 个月、Annual Return 同期。

## 观测到的时长与费用
- 台账与凭证目录:每天 2–5 分钟;季度申报准备 30 分钟。
- 首期 ITC 估算 $355–625,实际清单 ≈$447 + 后续周发票各 ≈$167.5。
- Apple 设备订单示例:小计 $5,658 + HST $735.54 = $6,393.54(HST 落发货季度)。

## 坑与检查项
- ☐ 教育商店买公司设备 → 企业商店重下。
- ☐ 普通结账把公司名塞进 First/Last Name → 勾 business address 用 Company Name 字段。
- ☐ 美国 SaaS 的 HST 拿去抵 → 不可抵;给税号止税。
- ☐ 虚拟地址订阅在个人邮箱名下 → 请服务商改抬头。
- ☐ 以旧换新退款进公司账户没记股东借款 → 记。
- ☐ 凭证只存合同包不存季度目录 → 两处。
- ☐ 设备 HST 记错季度(按下单而非发货)→ 按发票日期。
- ☐ 会计师包缺"迁移完成日"与"个人期报告" → 收入切分算不清。
