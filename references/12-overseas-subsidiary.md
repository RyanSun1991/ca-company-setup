# 12 · 海外(上海浦东)全资子公司筹办:已确定的步骤与文件清单(进行中,只写已定内容)

> 状态口径:真实项目 2026-09-07 启动,截至 2026-09-18 **尚未核名、未递交工商申请、未认证、未开户、未付款**;已完成的是主数据、文件草稿、地址方案与询价、加拿大文件翻译底稿与认证清单。以下只沉淀"已确定的步骤与文件",未定项标【待定】。

## 目标
以加拿大母公司 100% 持股在上海浦东设立有限责任公司(外国法人独资),不租实体办公室,负责人在加拿大远程办理,首期低出资。

## 前置条件(母公司侧)
- 母公司已稳定运行:Certificate + Articles、Minute Book 已签署交割(名册不能还是"预备稿")、IP 转让已交割、银行账户有流水、BN。
- 中文字号已定(01 §5)。
- 决定:董事 / 法定代表人 / 经理人选与国籍(中国籍控制人涉及 37 号文返程投资判断)、总注册资本(RMB 10 万,5 年内缴足)、首期出资意向(CAD 1–2 万)、经营范围(软件/AI/信息技术服务、软件销售、数据处理、咨询、进出口)。
- **中国手机号 + 境内联络人**是比地址更硬的缺件。

### 1b. 低首期出资测算(已定结论)
- 结论:普通软件/技术服务/非许可类咨询,**CAD 10,000–20,000 可以作为首期货币出资**;现行公司法无"外资首笔缴满 100 万"要求;2014 年改革已取消外商投资公司首次出资比例限制,但认缴总额须**自成立起 5 年内缴足**(法定提前缴纳情形除外),出资金额与日期写入章程。
- 换算(加拿大央行 2026-09-04:1 CNY = CAD 0.2062 → 1 CAD ≈ ¥4.85,指示性):CAD 10,000 ≈ ¥48,497;CAD 20,000 ≈ ¥96,993 —— **CAD 20,000 已接近 10 万总认缴**;实际按银行入资折算口径记账,超出认缴的部分不自动记注册资本;各期人民币认缴额合计 = 100,000。
- **首期资本 ≠ 启动总预算**:若 CAD 1–2 万指汇入中国公司的资本金,加拿大已付的公证/认证/翻译/快递另算;若指整个项目预算,先扣掉母公司在中国设立前直接支付的费用与银行手续费,再定净汇入额。**同一笔已付给公证人/代办的钱不能同时算中国实收资本**;个人对加拿大母公司的借款也不能冒充对中国公司的出资。
- 银行的最低余额/套餐门槛/首笔存入要求与法定注册资本是两回事,分项问;"低首期可合法安排" ≠ "银行一定开户"。

### 2. 加拿大文件认证(Apostille)
- 中加《取消外国公文书认证要求的公约》2024-01-11 起生效:安省公文书用 **附加证明书(Apostille)** 替代领事认证;安省由 **Official Documents Services(ODS)** 办理:政府正式文件 **CAD 32/件**、经公证法律文书 **CAD 16/件**(公证人费另计);纸质递交;Ottawa Courthouse 现场或邮寄多伦多(收件后 15 工作日);1991 年起的安省商业登记文件可免先公证,**私人签署文件(决议、授权书)须安省公证人**;ODS 不认证内容。
- 顺序:先拿上海接收方(登记经办 / 银行)的逐件清单 → ODS 资格检查按文件类型逐件确定路径 → 私人文件**定稿并签署后**再公证(不为未定资本/人选的草稿办认证)→ 递交付款 → 取得后按接收方要求中文翻译(含证明书本身)→ 扫描连续页归档,记快递单号、接收人、原件去向。
- PDF 打印 ≠ 必然可用;先由接收方与 ODS 确认纸件形式。

### 3. 注册地址(集中登记地 / 住所托管,不租实体)
- 法规:沪府办规〔2024〕2 号(集中登记地,一址多照,不分内外资);浦东实施意见(2024-10)与《浦东新区经营主体住所托管办法》(2026-02-13 施行);临港住所细则(托管协议可作住所使用证明;无法联系 → 经营异常名录);人行 2021 指引:**银行不得仅以集中登记地拒绝小微开户**。
- 推荐顺序:A 临港官方集中登记地(镇企业服务中心,无中介)> B 临港认定托管机构(含外资经办代理的园区地址)> C 浦东核心区园区集中登记地(问门槛,要求抬高资本即放弃)> D 浦东本部认定集中登记地;不考虑自贸区 2–2.5 万/年地址与无认定文件的"个人转让虚拟地址"。
- **价格纪律**:地址 ¥0 首选,≤¥1,500/年保底;真正盯的是**三年总成本 = 地址费 + 强制捆绑记账费(小规模纳税人市价 ¥200–300/月)+ 联络人/送达服务费 + 迁出成本**;"免费地址"靠税收返还,零税收企业会被捆绑记账或第二年收费。
- **统一九问**(五家同一组便于横向比):①接受外国法人独资 / 10 万资本 / 零雇员 / 法人在境外 ②地址法律身份(认定文号、公示链接、托管协议范本、住所系统合同编号样式)③第 1/2/3 年含税价、按年付、押金、锁价、零收入加价 ④是否捆绑记账、月费、可否分开解约 ⑤境内联络人与法律文书代收(费用、时限、是否提供中国手机号)⑥银行核址配合、近一年开户银行、外资开户案例 ⑦外资经办费与母公司文件公证/Apostille/翻译清单、必须到场环节 ⑧退款/迁址/失去资格的通知期 ⑨实际经营地在境外时如何报送场所信息。淘汰:①②任一为否即淘汰;③超纪律且⑤⑥无增值淘汰;④捆绑 >¥300/月或不可分离降级。
- 询价从 `partnerships@` 发;**首轮口径:不主动披露注册资本数字与法定代表人国籍/居住地,不附证件、住址、账号、流水**;"发前先确认"规则(用户要求后,每封由用户放行)。

### 4. 银行预沟通(与注册并行,不作前置)
- HSBC 中国(官方远程录像开户意愿核验;官方联系表单转介上海团队)与中国银行上海(企业账户见证通,海外中行机构协助核验;上海分行对公团队转接)并行;**注册不等待任何银行预批准**。
- 问题表:回复人官方身份 / 接受新设境外法人独资 / 法人 UBO 证件组合 / 无需赴华路径与必须到场人员 / 境内经办与印鉴 / 集中登记地接受与核址方式 / 新母公司短流水替代 / 37 号文判断材料 / 首期 CAD 1–2 万可行性(最低余额、首笔、总认缴分开问)/ CAD 直汇资本金 / 可开账户范围 / 入账结汇分红材料 / 境外网银登录与 UKey 寄送 / 制单复核权限 / 全部费用 / 强制产品。
- 只有"哪些人在何地完成哪项核验、哪个地址类型可用、所需文件与费用"的书面答复才算银行确认。

### 5. 上海企业登记(一网通办)
- 入口 yct.sh.gov.cn;**账号须完成"中级实名认证"(本人证件核验/人脸,✋ 不可代)**;新版系统 2025-12-02 起;保留"在线填报/预检 + 境内授权经办递交纸件"备选(境外股东全程电子签名未获保证)。
- 顺序:名称申报 → 投资人录入(母公司法定名、加拿大/安省、OCN、主体资格文件)→ 章程与任职 → 住所与联系(经办人、联络员、送达接受人)→ **外商投资初始报告** → **受益所有人备案**(法人股东不符合自然人小额免报;穿透到自然人)→ 正式申请(申请号/受理回执)→ 领照(统一社会信用代码)。登记环节免费、材料齐备后当场/3 工作日。
- 领照后:电子执照、印章保管制度、税务(主管机关、财务负责人/办税员、税种、周期、发票额度)、银行正式 KYC。

### 6. 首期资本金入境(顺序)
银行 KYC → 境内直接投资基本信息登记 → 资本金账户 → 母公司汇入(汇出人 = 母公司;受款人 = 核准公司;金额币种股本性质与章程一致;BMO 可否直汇 CAD、收款行是否接受 CAD)→ 入账登记 → 结汇/支付。**完成标准 = 银行确认到账 + 中国账簿记实收资本 + 出资证明 + 公示**,不是"电汇已发出"。2025 年 43 号文取消的是前期费用登记与部分境内再投资登记,**未取消新设 FDI 手续**。个人对加拿大公司的借款不能冒充对中国公司的出资;加拿大已付的认证费不能同时算实缴资本。

### 7. 后续申报(会计团队交付)
中国单独账簿、申报日历、年度汇算与年报、外商投资年度报告、BO 维护、关联交易证据;母公司 **T1134**(2021 及以后税年:税年结束后 10 个月)/ T106 评估;中国子公司税务居民/实际管理判断;母子公司间服务/IP 许可/借款/分红分别留合同与账簿(尚未形成合同的管理费/IP 费不能先作提款通道)。

## 坑与检查项
- ☐ 把"免费地址"当免费 → 看三年总成本与捆绑。
- ☐ 用未签署的名册/IP 协议草稿向接收方声明母公司确权 → 先核实签署与交割。
- ☐ 以 Resident Canadian = No 推断国籍或以国籍推断 37 号文 → 个案判断进银行问题表。
- ☐ 把银行预批准设成工商前置 → 并行。
- ☐ 首轮邮件披露资本数字与法定代表人国籍 → 待对方问及再答。
- ☐ 为草稿办 Apostille → 定稿签署后再办。
- ☐ 用 2025 年 43 号文跳过 FDI 手续 → 不适用。
- ☐ 账号缺中级实名认证却以为"尚未登录" → 阻点是认证。
