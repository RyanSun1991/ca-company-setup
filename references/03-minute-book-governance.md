# 03 · Minute Book 与公司治理:Bylaw、决议、股权、登记册、ISC、IP 转让、股东借款、高管任命、签署打印包

## 目标
注册当晚起草、五轮审阅内定稿、股本入账当天完成签署交割:一套能直接给银行/EOR/Apple/海外接收方看的 Minute Book,并建立"每一笔股东注资、每一次任命都有决议"的习惯。

## 前置条件
- Certificate + Articles PDF 到手(OCN、成立日、股份条款以官方为准)。
- Intake C1–C5 决定:一人独资、是否有 IP 转入、财年、高管口径、股本 $100、借款授信上限。
- 银行账户(05)开好后才能完成"交割"签名。

### 2. 股权发行方案(真实项目定稿)
- **101 股普通股全部在同一"交割日"发行**:100 股现金对价 $1/股 = $100(存入公司账户当天成立),**1 股 IP 财产对价**(Consideration Share)。
- 董事按 OBCA **s.23(4)** 认定财产公允价值不低于 $1,并把 $1 计入 stated capital → 合计 $101。
- **纯股对价、无现金 boot**:免去 $1 支付凭证与 T2057 boot 分摊;协议保留 **ITA s.85 逐项财产选举**路径(附表列财产与对价分配),是否申报 T2057、elected amount 定多少交秋季会计师,截止 = 转让年度最早的申报截止日(真实项目 2027-04-30)。
- 若只写"$1 现金"对价,会永久关闭 s.85 路径——不要这么写。

### 3. 创始人 IP 转让协议要点
- 范围:已上架/未上架 App(bundle ID、App Store ID)、源码/后端/模型/设计/素材、品牌名与字标、官网内容、goodwill、所有 IP 权利含追诉权、改进与衍生;排除第三方/开源组件。
- 精神权利放弃(Copyright Act)。
- Further assurances:配合 Apple 开发者账户/App Store 资产转移。
- **过渡期收入信托条款**:以 Apple 财务报表的 **purchase (transaction) date** 切分——Effective Date 起的交易(含新订、续订)净额归公司,由个人代收后 **30 天内**转公司并附报表;之前的归个人;**跨期订阅不按日摊**;退款/拒付跟随原交易。
- s.132 利益披露 + 提交股东特别决议确认。
- 执行日期栏手写(签署当天),不预印。

### 4. 股东借款决议(运营资金最干净的注资方式)
- 授信上限 **CAD $25,000**(累计未偿本金;超了先过提额决议);**免息、无担保、随时可还**,但还款不得导致公司无法偿债;s.132 书面披露;每笔记台账。
- 操作:**先签决议再转账**(日期填首笔转账当日或更早);个人账户 → 公司 Chequing,e-Transfer 备注 **"Shareholder loan"**;台账列:日期 / 方向 / 金额 / 转账方式备注 / 累计未偿余额。
- 方向提醒:股东借给公司干净;**公司借给股东**有 ITA s.15(2) 计入收入风险——别从公司账户给个人垫钱。
- 为什么不多发股本:股东借款还款免税、无利息申报、一纸决议;股本抽回要减资程序。
- 真实项目:$3,000 × 3 笔(9/1、9/7、9/15),按周成本(EOR ≈$1,456/周)分批入。

### 5. 高管任命体系(有真人加入时)
- **officers(President/CEO/CFO/CTO/Secretary/Treasurer/"Director" 头衔)必须经董事决议任命**;其余内部 title 由 CEO 授予。
- "Director" 作为**高管头衔** ≠ OBCA 董事会董事:不改 OBR 登记、不触发 Notice of Change、不承担董事法定责任;决议里明写 "not an appointment to the board" 与**权限边界**(如:只监督派驻人员、确认工时、担任客户联系人;不得签合同/开支/开户/以公司名义签字)。
- 被任命人签 **Consent to Act**(同意任职 + 确认权限边界 + 保密 + 工时确认责任 + 可辞任)。
- 生效日填实际开始履职日;更新高管名册;通知第三方(如 EOR)时附邮箱。
- 若要进董事会:股东决议 + 15 日内 OBR Notice of Change + 董事法定责任。
- 签字授权边界表(写进 `08-职位与任命体系`):银行/支付/借贷=President(唯一签字人,决议 §6);合同=President & CEO(§8);发股/任命/分红=董事会;日常采购 < $5,000 = CEO 或书面授权人。
- 早期不虚设 C 字头;外包/派驻人员 title 用职能名。

### 6. 签署打印包(html → pdf)
- 把要签的文件合成一个 HTML(`@page { size: letter; margin: 20mm }`;每份 `.doc { page-break-after: always }`;签名块 `page-break-inside: avoid`;顶部 `.screen-note` 打印时 `display:none` 的签署说明),用 `scripts/html2pdf.sh` 生成 PDF;**同时出一份 clean 版**(去掉所有说明行/黄底提示),给对方签或正式归档用。
- **签署顺序(单一交割日方案)**:
  1. 注册当晚只签**纯董事身份** 2 处:By-law ENACTED(Director)、董事决议。
  2. 股本 $100 入账当天再签**交割** 5 处,按序:IP 转让协议 ×2(执行日期手写当天)→ By-law CONFIRMED(Shareholder)→ 股东决议 → 股票凭证。
  这样 101 股同日发行,转让日 = 税务处置日 = 发行日,全链一致;若当天没存款,交割 5 处整体顺延并改日期重印。
- 生效日期预印在文件里;签完扫描 PDF 存回 `03-公司治理/`,纸质留存。
- 电子签约定:对外证明信可用 `/s/ 姓名` 斜体 + "Signed electronically on <date>";法律文件优先手签扫描。

## 观测到的时长与费用
- 起草 1 晚;五轮审阅 2 天(8/23 起草 → 8/25 定稿 v4/v6);签署两晚;$0 费用(自制,无律师)。
- 后续每次任命/借款决议约 30 分钟起草 + 打印签署。

## ✋ 用户本人必须做

- 存 $100 股本(交割前置)。
- 决定:高管口径、借款上限、是否设 Secretary/Treasurer。

## 坑与检查项
- ☐ 把 IP 对价写成 "$1 现金" → s.85 路径永久关闭。
- ☐ 股票凭证/股东决议在存款前签 → 股份"发行"早于对价,与 OBCA 实缴要求矛盾;按两晚顺序签。
- ☐ 名册在交割前就写"已发行 101"→ 加"预备稿声明:对价交付后生效,此前读作 0"。
- ☐ ISC 含生日/住址 → 不进任何对外文件、不进 CRA 指引之类的操作文档(真实项目曾误写 SIN/生日/邮编到 CRA 指引,次日抹除)。
- ☐ 任命"Director"没写权限边界 → 第三方以为他能签约。
- ☐ 借款超 $25k 没提额决议;台账漏笔(真实项目第二笔金额补了 8 天)。
- ☐ 用挂名者做工时审批人 → 对雇主/员工虚假陈述;必须真人 + 任命 + Consent。
- ☐ 打印包忘出 clean 版 → 对方签的文件上带内部说明。
