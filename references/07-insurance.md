# 07 · 商业保险:CGL + 科技 E&O(经纪、报价结构、限额谈判、COI 与 additional insured、RST、保单审核)

## 目标
在首名(EOR 派驻)员工开工前拿到 CGL 保单与列 EOR 为 additional insured 的证书;保费按最便宜的合规档;保单要素与申报口径全部留档。

## 前置条件
- EOR 合同(SOW)里的保险条款(限额、additional insured 要求)——决定"合规档";若无 EOR/客户要求,可延后购买。
- 公司信息表(法定名、注册地址、成立日、业务描述、预计收入、美加收入占比、是否处理健康数据、有无雇员)。
- 公司电话与 `hello@` 邮箱可接来电/来信;公司账户或信用卡付款。

## 步骤

### 1. 选经纪 / 平台(真实项目三路并行)
| 平台 | 体验 | 结论 |
|---|---|---|
| **Zensurance**(在线经纪,多承保商面板) | 全程在线即时报价;E&O + Cyber 捆绑套餐;COI 即时免费;48h 内可全额退款;经纪人可邮件改档重报 | **主线**(最低价、当天出单) |
| Foxquilt | 申请提交后转人工核保,发 "Technology Main Application Form" PDF 要填,2–5 工作日 | 赶不上生效日;放弃,续保期再比 |
| APOLLO | 经纪转介模式 | 未提交 |
市场区间(一人软件公司、安省、CGL $2M):$450–900/年。

### 2. 申报口径(如实;与 CRA/注册/发票一致)
行业 Software Development;预计收入(如 $10k/首年);**收入地域**(若 App 已限售加拿大 → 100% Canada,0% US,保费更低且 USA Jurisdiction Excluded);无美国实体/员工;无房产内容物;是否收集健康数据(**如实勾**,两份申请答案冲突会被经纪追问);经营地址 = 注册地址(虚拟办公室,远程经营);雇员数(EOR 派驻 ≠ 直雇);行业经验(公司 0 年 + 负责人 N 年,分开说)。营销同意全部拒。

### 3. 限额结构与谈判
- 承保商各档常是**"每次事故 = 累计"扁平结构**($2M/$2M、$3M/$3M、$5M/$5M)——SOW 若写 "$2M per occurrence + $5M aggregate",$3M 档达不到累计,只能买 $5M。
- **先问 EOR 能否接受更低的对等限额**:真实项目 EOR 邮件说 "$2M/$2M 可替代 SOW 的 $5M" → 双方书面改为 $2M/$2M → 保费从 $1,065 降到 **$765/年**。要 EOR **书面确认"$2M/$2M 证书满足 SOW 保险条款"**(相当于 SOW 该条书面修订)。
- E&O 套餐强制底额 $100k(claims-made,追溯日 = 保单起始);D&O / Property 排除。
- **月付 vs 年付**:月付 $71+税 ×12 = $852 vs 年付 $765(+11.4%,余额递减实际年化 ≈20%);公司资金来自 0% 股东借款 → 年付;结账页只有全年一次性刷卡,分期须经纪另设(保费融资)。用户若倾向月付,结账前就说。

### 4. 出单与文件
- ✋ 用户在报价页 "Proceed to Checkout" 刷卡(付款不代办);成功页 "Your payment has been received…";收据(Stripe 收据发到 `hello@`/个人别名)。
- 1–2 个工作日经纪发:**Policy Document**(约 100 页,含 Declarations)、**COI**、**Additional Insured Certificate(EOR 法定名与地址;Primary & Non-Contributory;Waiver of Subrogation)** → 存 `11-保险/`。
- 出单后经纪可能来电称"申请与保单不一致"→ 请其**邮件列明具体字段**,如实逐条答(收入、经营描述、经验年数、健康数据),解释"第二份申请"若为结账默认值并非本意,请确认承保并催 COI。保单已出 = 核保通过。
- 把 AI 证书 + COI 从 `partnerships@` 发 EOR;也审阅 EOR 发来的对方 COI(见 08)。

### 5. 保单审核清单(`11-保险/01-保单审核-<date>.md`)
保单号 / 承保商 / 经纪地址;被保险人名称与地址;经营描述(经纪类目措辞 ≠ 我方申报语,略宽不影响);**保单期(以出单日起,可能晚于申请生效日)**;E&O 追溯日;保费 + **8% 安省 RST(不可抵 ITC)**;最低留存保费;地域(Territory Canada;USA Jurisdiction Excluded → 日后恢复美国销售先通知经纪);免赔 $1,000;索赔联系(网络类 / 其他);CGL 各分项(每次/累计/产品完工/人身广告/雇主责任扩展/雇员福利/非自有汽车/租户/医疗费/污染);附加被保险人背书;E&O + 网络第一方各限额与等待期;排除项(Electronic Data & Cyber Attack、War、Communicable Disease、Limited Manual Work)。

## 验证 / 证据
- 台账订单行:保单号、承保商、期、保费 + RST、收据号、文件位置。
- 总控待办行:限额、生效日、续保日;"业务变化须通知经纪"备注。
- 凭证目录**不**放保险(免 HST,RST 不可抵),但 T2 可扣。

## 坑与检查项
- ☐ 按 SOW 模板数字 $5M 直接买 → 先问对方能否接受 $2M/$2M,省 $300/年。
- ☐ 以为 $3M 档合规 → 每次=累计,累计不够。
- ☐ 申请填美加 75/25 后 App 限售加拿大 → 重报 100% Canada;两份申请答案不一致会被追问。
- ☐ 以为保单从申请生效日起保 → 实际从出单日;员工开工日当天出单就在保。
- ☐ 保险 8% RST 当 ITC → 不可抵。
- ☐ 想借用 EOR 的保单 → 保险按被保险人出单,不能"用";SOW 要求客户自持 CGL 并列 EOR 为附加被保险人。
- ☐ 分期入口只在经纪端 → 想月付要在结账前说。
- ☐ 恢复美国销售/加雇员/收入超量级不通知经纪 → 影响理赔。
