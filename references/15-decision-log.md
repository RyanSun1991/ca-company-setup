# 15 · 决策日志:每个关键选择的问题 / 备选 / 选择 / 理由 / 代价或后悔点 / 复用建议

> 格式固定六项。日期为真实项目决策日(2026)。

## D1 · 注册管辖区(08-23)
- **问题**:联邦 CBCA 还是安省 OBCA?
- **备选**:联邦(全国名称保护,$200 在线)/ 安省($300)。
- **选择**:安省 OBCA。
- **理由**:创始人非公民/PR,联邦要 ≥25% 董事 resident Canadian;安省 2021 起无董事居民要求;在线即时生效。
- **代价**:名称保护限安省;跨省经营要额外登记。
- **复用**:非公民/PR 一律省注册;公民/PR 且全国业务可考虑联邦。

## D2 · 虚拟商业地址 vs 家庭住址(08-23)
- **备选**:家庭住址(免费)/ 虚拟商业地址(≈$27+HST/月)/ 租办公室。
- **选择**:虚拟商业地址,董事送达地址同址。
- **理由**:Articles、OBR、D&B、Apple DSA trader 页、保险、收款平台全部公开或半公开注册地址;家庭住址零公开。
- **代价**:$30/月;账单抬头要请服务商改公司名;保险/CRA 需说明"注册地址,远程经营"。
- **复用**:默认选;月付先试,稳定后年付。

## D3 · 股权结构:100 现金股 + 1 IP 对价股,单一交割日(08-25,五轮审阅)
- **备选**:①100 股现金 + IP 以 $1 现金卖给公司;②101 股同日发行(1 股为 IP 对价);③IP 无偿贡献。
- **选择**:②,纯股对价,无 boot,保留 s.85。
- **理由**:"$1 现金"会永久关闭 s.85 路径;股对价让董事按 s.23(4) 认定价值即可;同日交割使转让日=处置日=发行日,会计师好算。
- **代价**:多一份 IP 协议与特别决议;需秋季会计师决定是否申报 T2057。
- **复用**:凡有现成 App/代码/品牌要进公司,照此结构。

## D4 · 高管申报只报 President + CEO(08-24)
- **备选**:一人兼 President/CEO/Secretary/Treasurer 四职 / 只报两条。
- **选择**:两条,Secretary/Treasurer 空缺由 President 代行。
- **理由**:名单全是同一人显得空洞;Initial Return、决议、名册口径一致。
- **代价**:有真人加入时补任命决议。
- **复用**:一人公司默认。

## D5 · 银行:BMO Essential,线上被拒后分行面谈(08-24→26)
- **备选**:BMO / RBC / TD / 数字银行。
- **选择**:BMO Essential($5/月,6 笔 e-Transfer)。
- **理由**:用户已有个人关系;新公司线上开户普遍被风控转分行,BMO 可当天预约两天后面谈。
- **代价**:面谈 1 小时;$5/月。
- **复用**:选用户有个人账户的大行;直接预约分行,别在线上耗。

## D6 · GST/HST 自愿注册、生效日回溯成立日、Quarterly(08-25 / 08-31)
- **备选**:不注册(<$30k 不强制)/ 注册 Annual / 注册 Quarterly。
- **选择**:注册,Quarterly。
- **理由**:纯支出期净退款;EOR 年进项 HST ≈$8k,按季回笼现金流。
- **代价**:每季一张 GST34(零活动也报);注册审核来电。
- **复用**:有 EOR/大额进项 → Quarterly;只有小额订阅 → Annual。

## D7 · Apple:原地转换而非新组织账户 + App Transfer(08-26)
- **备选**:新开组织账户($99)+ App Transfer + SIWA 用户迁移 / 个人账户原地转组织。
- **选择**:原地转换。
- **理由**:Team ID、证书、APNs、SIWA、未上架 App 全部保留;"工程量最大"的 SIWA 迁移整项消失。
- **代价**:依赖 Developer Support 排队(16 天);要 D-U-N-S + 公开官网 + 补件。
- **复用**:有已上架 App 一律原地转换。

## D8 · 用工:非研发岗走 EOR;研发主力直雇(08-24)
- **备选**:全部直雇(开 RP + payroll 工具)/ 全部 EOR / 混合。
- **选择**:首名(QA/PM,非研发)走 EOR;研发直雇。
- **理由**:EOR 让 payroll/ESA/WSIB 合规零负担、1 工作日入职;但 SR&ED 对挂靠员工只算 80% 且丢 55% proxy → 研发岗每 $10 万少 $2.1 万联邦。
- **代价**:18% markup;押金;THA 牌照灰区;Assignment Information 具名。
- **复用**:先问"这个岗算 SR&ED 吗",算就直雇。

## D9 · EOR 选 HQ Simple 18% 预付档(08-26→28)
- **备选**:HQ Simple(18–21%)/ CPS(~US$400 flat)/ TCWGlobal(报价制)/ Payroll Edge(持牌)/ Deel(US$599)。
- **选择**:HQ Simple 预付 18%。
- **理由**:费率公开、无最低人数、零杂费、**转直雇零费用零等待**、1 工作日入职、加拿大总部、首次沟通即资深顾问。
- **代价/后悔点**:THA 登记库查无(只有律师意见);锁价未入合同文本;年轻小所保单限额低需加保;intake 表单误读损失一天。
- **复用**:同一套 10 问询价;把"转直雇零费用"与"锁价入文本"作为两个硬指标;THA 号拿不到至少要书面法律立场。

## D10 · THA 牌照不作签约阻断项(08-28)
- **备选**:不给牌照号不签 / 按"签约包附号码"处理 / 接受律师意见。
- **选择**:不阻断,存档对方书面立场作尽职核查证据。
- **理由**:入岗时间优先;ESA 处罚针对"knowingly";对方有资质陈述条款与责任。
- **代价**:残余合规风险。
- **复用**:用户的商业决定;Claude 只负责把风险与证据写清。

## D11 · 雇佣合同保持无固定期限(09-01)
- **备选**:固定期限 8–12 个月 / 无固定期限 + ESA 最低解约。
- **选择**:无固定期限;8 个月写作 assignment 预估。
- **理由**:固定期限提前结束有付满剩余期限风险(Howard v. Benson);无固定期限 <1 年工龄 ≈1 周成本。
- **复用**:默认无固定期限。

## D12 · 保险:Zensurance,CGL $2M/$2M(09-02)
- **备选**:$5M/$5M($1,065)/ $3M(累计不够)/ $2M/$2M($765)/ Foxquilt 人工核保。
- **选择**:$2M/$2M,年付,Zensurance。
- **理由**:EOR 书面接受 $2M/$2M 替代 SOW $5M;承保商结构每次=累计;Foxquilt 2–5 天赶不上开工;月付实际年化 ≈20% 不如 0% 股东借款。
- **代价**:E&O 底额 $100k 捆绑;出单后经纪追问四项不一致。
- **复用**:先问合同方能否接受低限额;100% Canada 申报;年付。

## D13 · 收款:Stripe + Helcim 双通道(09-05→08)
- **备选**:只 Helcim(拒批风险)/ 只 Stripe(卡费高、无 Fee Saver)/ 双通道 / OTT Pay。
- **选择**:双通道并行,Helcim 主(加拿大 B2B)、Stripe 备 + 支付宝(中国客户)。
- **理由**:两家月费 $0;Helcim 卡费低 0.5–1.3 点且 Fee Saver 可转嫁、发票免费、次日到账;Stripe 唯一有 Alipay;Helcim 首次拒批时 Stripe 保底。
- **代价**:两套配置;Stripe 首笔 7 天;WeChat 两家都不行。
- **复用**:照抄分流规则;测试付款记股东往来。

## D15 · 创始人 2026 不发薪(09-05)
- **备选**:10 月起 $5k/月吃 SR&ED / 不发薪,股东借款注资。
- **选择**:不发薪。
- **理由**:创始人另有一份高收入全职工作,边际税率 43–48% ≈ SR&ED 退款率 45–57%;主张 100% 工时研发审计风险高。
- **代价**:SR&ED 只靠承包商/员工支出;记录制度照常。
- **复用**:先算边际税率 vs 退款率;收入低的年份再发。
